## THE HEADLINE FEATURE — point-to-drive steering
This is the reason the game exists, so make it excellent. Steering is done by **pointing**, not by holding a wheel:
- Direction and throttle are read **relative to the car's position on screen** (the camera keeps the car centered). The vector from screen-center to the pointer gives the desired heading; the distance gives throttle (`throttle = clamp(dist/150, 0, 1)`, `steer = clamp(angleDiff*1.5, -1, 1)` where `angleDiff = wrapToPi(atan2(aim) - heading)`).
- **Desktop:** hold the mouse button to drive toward the cursor; release to coast. Move the mouse (even un-held) to aim a reticle. `Shift` (or right-mouse) = drift, `Space` = fire stored mini-turbo, `B` = brake, `R` = reset, `Esc` = garage. WASD/arrows are a discrete fallback when the pointer isn't engaged.
- **Touch:** drag anywhere to steer/throttle toward the finger; on-screen `DRIFT` / `BOOST` / `BRAKE` buttons. Same underlying model as mouse.
- Unify all input into one `{throttle, steer, drift, brake, boost}` snapshot per tick and feed it to `step()`.

## C. One physics tick — run in this exact order every `dt`
0. `surfaceMult = onTrack ? 1 : grassMult`; `spd = |vel|`.
1. **Steering rack:** slew-limited toward `steer*maxWheel` at `rackRate`; if `|steer|<0.05`, self-center toward 0 at `centerSpring`. Push `(t, wheel)` into a 0.35 s ring buffer.
2. **Weight transfer (smoothed):** `target = (throttle*0.7 - (brake?0.6:0))*wtFactor`; lerp `wt` toward it at `min(1, wtSmooth*dt)`. (State kept for parity; not multiplied into grip.)
3. **Drag:** `air = airDrag*spd²`, `roll = rolling*max(0,spd)`; `dragMult = spd>0.1 ? (spd - min(spd,(air+roll)*dt))/spd : 1`.
4. **Speed grip loss:** `gripT = clamp((spd-gripLossStart)/(gripLossFull-gripLossStart),0,1)`; `speedGrip = 1 - gripT*gripLossAmt`.
5. **World→local:** `fwd = vx*cos+vy*sin`, `lat = -vx*sin+vy*cos`.
6. **Effective lateral friction (gradual LERP):** target = `(drift?fricD:fricN)*speedGrip*surfaceMult`; lerp `curLatFric` at `(drift?1/entryTime:1/exitTime)*dt`.
7. **Lateral PARTIAL BLEED (the soul — never hard-clamp):**
   `cap = |fwd|*latFric*(drift?1.05:0.95)`, `bleed = drift?bleedDrift:bleedNormal`.
   If `|lat|>cap`: `newLat = sign(lat)*(cap + (|lat|-cap)*(1-bleed))`; else `newLat = lat*(1 - min(1, latFric*2.2*dt))`.
8. **Forward force:** `scrub = |wheel|*0.3*(spd/200)`; `newFwd = fwd*dragMult + throttle*engine*dt - scrub*spd*dt`; clamp to `[-maxSpd*0.4, maxSpd]` where `maxSpd = max*surfaceMult*(1+dsb)`. Brake: if braking and `fwd>0`, `newFwd = max(0, newFwd - engine*2*dt)`. Active boost: `newFwd += boostPow*dt`, decrement `boostTime`.
9. **Local→world + yaw + integrate:** `vx = newFwd*cos - newLat*sin`, `vy = newFwd*sin + newLat*cos`; `heading += (wheel*(spd/120)*yawWheel + newLat*yawFromSlip*0.012)*dt`; `pos += vel*dt`.
10. **Soft wall (IMPORTANT — push INWARD):** find closest point on centerline; if `dist>hw`, `normal = (pos-closest)/|.|` (outward), `pen = dist-hw`, then **`pos -= normal*pen*wallPush`** (toward the ribbon — pushing `+=` outward is a runaway bug; the reference prototype only hides it via a non-unit normal). If `vel·normal>0`, damp: `vel -= normal*(vel·normal)*wallDamp`. On a cooldown, register a wall hit (shake, and if mid-scoring-drift subtract `min(driftScore,100)`).
11. **Drift detect:** `slip = wrapToPi(heading - velDir)`; `driftAngle=|slip|`; `isDrift = drift && speed>60 && driftAngle>thr`.
12. **Feint:** on the tick a scoring drift first turns true, if the 0.35 s wheel history has a sign flip with `|wheel|>0.15`, set `feintApplied` once (adds `feintBonus` to perceived angle). Clear when not drifting.
13. **Countersteer:** true when drifting and `sign(slip)!=sign(wheel)` and `|wheel|>0.15`.
14. **Scoring while drifting:** `combo += dt`, `comboTimer = comboGrace`, `charge = min(charge+dt*chargeRate, chargeMax)`. Angle mult: 1.3 in `[optLow,optHigh]`, 0.5 above `overRot`, else 1.0; ×1.15 if countersteering. `score += driftAngle*speed*dt*(1+combo*comboGrowth)*bonus*angleMult`. `dsb = min(dsb+dsbRate*dt, dsbMax)`. On the **exit edge**, if `charge>mtBlue` bank a STORED boost by tier (do NOT auto-fire); reset `charge=0`, `combo=0`; decay `dsb` when not drifting.
15. **Fire stored mini-turbo:** on boost press, if `stored && !boostActive` → activate for the tier duration; consume the press; second press does nothing until a new charge banks.
16. **Combo bank (grace):** if not drifting and `comboTimer>0`, decrement; on expiry `driftTotal += driftScore; driftScore=0; combo=0`. Visible score = `driftTotal + driftScore`.

## Acceptance tests (make these pass against the real `step()`)
1. Idle: zero input → speed decays; wheel self-centers to ~0 within 0.4 s.
2. Straight line: throttle 1, no steer/drift → approaches `max` asymptotically, never overshoots by >~1%.
3. Slide: at speed ≥200 with drift held and steer≠0, `|lat|` stays non-zero for many ticks (not snuffed in 1–2 frames).
4. Grip recovery: release drift while sliding → `curLatFric` returns to normal over ~0.28 s, not instantly.
5. Mini-turbo tiers: sustained scoring drift for 0.5 / 1.2 / 2.2 s → stored power 120 / 200 / 320; fires once on boost press, second press does nothing until re-charged. (Test with a *controlled* slide, e.g. imposed slip ~0.5 rad — a full-lock hold correctly spins out and won't sustain.)
6. Scoring: more time in the 0.4–0.8 rad band → more score than shallow/over-rotated at the same speed.
7. Grass: off-track `surfaceMult=0.45` caps top speed hard.
8. Cars differ: identical open-loop input (accelerate, then a gripping arc) yields different final heading and speed for muscle vs super.
