# Prompt: Implement Arcade Slip-Angle Drift Car Physics

Copy everything below the line into your offline model. This is a complete,
engine-agnostic implementation brief for the drift-car feel from Drift Racer.
Every constant is the real shipped value. Reproduce it literally — do not
"simplify" the lateral bleed into a hard clamp, and do not use a rigid body.

---

## Role

You are implementing a **top-down 2D arcade drift car**. The car is a
**kinematic body** with hand-authored slip physics (NOT a rigid body / NOT
Box2D/Rapier torque tires). Physics runs on a **fixed timestep** (prefer 60 Hz
`dt = 1/60`) so feel is frame-rate independent.

Deliver:

1. A plain-data config block (global constants + 3 car configs).
2. A single `step(car_state, input, surface, dt) -> car_state` function that
   advances one physics tick and returns updated state plus side-effects
   (score deltas, wall hits, boost fire events).
3. Pseudocode or the target language of your choice — but keep the math 1:1.

Do **not** invent alternate physics systems (Pacejka tires, other simulators).
Port this model exactly.

---

## Coordinate system

- Top-down 2D plane. `+X` right, `+Y` down or up — pick one and stay consistent.
- `heading` is the car's nose angle in radians (0 = +X).
- Velocity is a world-space `Vector2`.
- Per tick you convert velocity into **car-local** forward and lateral axes,
  modify those scalars, then write them back to world space.

Car-local basis for heading `h`:

```
forward = ( cos(h), sin(h) )
right   = (-sin(h), cos(h) )   # left-handed 90° of forward
forward_vel =  vel · forward
lateral_vel =  vel · right
```

Write-back:

```
vel = forward_vel * forward + lateral_vel * right
```

(Equivalent component form used in the shipping code when `right = (-sin, cos)`:)

```
vel.x =  new_forward * cos_h - new_lateral * sin_h
vel.y =  new_forward * sin_h + new_lateral * cos_h
```

## C. One physics tick — ORDERED ALGORITHM

Run exactly in this order every fixed `dt`.

### 0. Surface

```
on_track = surface_query(pos)   # true if on asphalt ribbon
surface_mult = 1.0 if on_track else grass_speed_mult
spd = |vel|
```

### 1. Steering rack (slew-limited + self-center)

```
target_wheel = steer * max_wheel_angle

if |steer| < 0.05:
    center = steering_center_spring * dt
    if |wheel_angle| < center: wheel_angle = 0
    else: wheel_angle -= sign(wheel_angle) * center
else:
    diff = target_wheel - wheel_angle
    max_move = steering_rack_rate * dt
    wheel_angle += sign(diff) * min(|diff|, max_move)
```

Weighty steering — never snap the wheel instantly to input.

### 2. Weight transfer (smoothed)

```
accel_factor = throttle * 0.7 - (0.6 if brake else 0.0)
target_wt    = accel_factor * weight_transfer_factor
weight_transfer_s += (target_wt - weight_transfer_s)
                    * min(1.0, weight_shift_smoothing * dt)
```

(State is kept for parity / future load-sensitive grip. The shipping step does
not multiply friction by `_wt` yet — keep the update so numbers stay ready.)

### 3. Drag

```
air_drag   = air_drag_coeff * spd * spd
rolling    = rolling_resistance * max(0, spd)
total_drag = min(spd, (air_drag + rolling) * dt)
drag_mult  = (spd - total_drag) / spd   if spd > 0.1 else 1.0
```

### 4. Speed-dependent grip loss

```
grip_t = clamp( (spd - grip_loss_start_speed)
              / (grip_loss_full_speed - grip_loss_start_speed), 0, 1 )
speed_grip = 1.0 - grip_t * grip_loss_amount
```

High speed feels looser. Low speed is planted.

### 5. World vel → car-local

```
cos_h = cos(heading); sin_h = sin(heading)
forward_vel =  vel.x * cos_h + vel.y * sin_h
lateral_vel = -vel.x * sin_h + vel.y * cos_h
```

### 6. Effective lateral friction (gradual LERP on drift press/release)

```
normal_fric = car.lat_friction_normal * speed_grip * surface_mult
drift_fric  = car.lat_friction_drift  * speed_grip * surface_mult
target_fric = drift_fric if drift else normal_fric
lerp_rate   = (1 / drift_gradual_entry_time) if drift
              else (1 / drift_gradual_exit_time)
current_lat_fric += (target_fric - current_lat_fric) * min(1, lerp_rate * dt)
lat_fric = current_lat_fric
```

Exit is slower than entry → slide-out after you release the drift button.

### 7. Lateral grip — PARTIAL BLEED (the soul of the feel)

**Do not hard-clamp lateral velocity to a ramp.** Bleed only a fraction of the
excess each tick so the car can hang off-heading.

```
lat_cap = |forward_vel| * lat_fric * (1.05 if drift else 0.95)
bleed   = lat_bleed_drift if drift else lat_bleed_normal

if |lateral_vel| > lat_cap:
    excess      = |lateral_vel| - lat_cap
    new_lateral = sign(lateral_vel) * (lat_cap + excess * (1.0 - bleed))
else:
    # gently kill residual lateral under the cap
    new_lateral = lateral_vel * (1.0 - min(1.0, lat_fric * 2.2 * dt))
```

Interpretation of `bleed`:
- `0.72` normal → keep 28% of excess slide
- `0.92` drift  → keep only 8% of excess (more control while still sliding)

### 8. Forward force / top speed / brake / active boost

```
steer_scrub = |wheel_angle| * 0.3 * (spd / 200.0)
new_forward = forward_vel * drag_mult
new_forward += throttle * car.engine_power * dt
new_forward -= steer_scrub * spd * dt

max_spd = car.max_speed * surface_mult * (1.0 + drift_speed_boost)
new_forward = clamp(new_forward, -max_spd * 0.4, max_spd)

if brake and forward_vel > 0:
    brake_force = car.engine_power * 2.0
    new_forward = max(0, new_forward - brake_force * dt)

if boost_active:
    new_forward += boost_power * dt
    boost_time  -= dt
    if boost_time <= 0: boost_active = false
```

### 9. Write local → world, rotate, integrate position

```
vel.x = new_forward * cos_h - new_lateral * sin_h
vel.y = new_forward * sin_h + new_lateral * cos_h

# Yaw = geometric rack contribution + slip-angle feedback
# so the car rotates INTO the slide (not just around the wheel)
rotate_vel = wheel_angle * (spd / 120.0) * yaw_wheel_scale
           + new_lateral * yaw_from_slip * 0.012
heading   += rotate_vel * dt

pos += vel * dt
```

### 10. Soft wall (optional coupler)

If you have a track ribbon of half-width `hw`:

```
Find closest point on centerline polyline to pos.
If distance > hw:
    normal      = (pos - closest).normalized()   # outward
    penetration = distance - hw
    pos        += normal * penetration * wall_push
    if vel · normal > 0:
        vel -= normal * (vel · normal) * wall_damp
    # emit wall_hit if cooldown allows; if mid-scoring-drift, subtract
    # min(drift_score, 100) from the open drift_score
```

Walls are a **soft push**, not a magnet and not a hard bounce.

### 11. Drift detection

```
new_speed   = |vel|
vel_dir     = angle(vel) if new_speed > 1 else heading
raw_slip    = wrap_to_pi(heading - vel_dir)     # signed, [-π, π]
drift_angle = |raw_slip|

is_drifting = drift
              AND new_speed > 60
              AND drift_angle > car.drift_threshold
```

### 12. Feint (Scandinavian flick)

Keep a ring buffer of `(time, wheel_angle)` for the last **0.35 s**.

On the frame a scoring drift first becomes true, if the recent wheel samples
contain a **sign flip** with `|wheel| > 0.15`, set once:

```
feint_bonus = feint_angle_bonus   # 0.08 rad — may be added to perceived angle
feint_applied = true
```

Clear `feint_applied` when `is_drifting` becomes false. Do not retrigger mid-slide.

### 13. Countersteer

```
is_countersteering =
    is_drifting
    AND sign(raw_slip) != 0
    AND sign(wheel_angle) != 0
    AND sign(raw_slip) != sign(wheel_angle)   # steering opposite the slide
    AND |wheel_angle| > 0.15
```

### 14. Drift scoring + mini-turbo charge + drift-speed boost

While `is_drifting`:

```
drift_combo      += dt
drift_combo_timer = combo_grace_time
drift_active      = true
drift_charge      = min(drift_charge + dt * charge_rate, charge_max)

# Angle zones
if drift_angle in [optimal_low, optimal_high]:   angle_mult = 1.3
elif drift_angle > over_rotate_threshold:          angle_mult = 0.5
else:                                              angle_mult = 1.0
if is_countersteering: angle_mult *= 1.15

combo_mult  = 1.0 + drift_combo * combo_growth_rate
score_added = drift_angle * new_speed * dt * combo_mult
              * car.drift_bonus * angle_mult
drift_score += score_added

# Sustained-drift top-speed mult
if drift_speed_boost_enabled:
    drift_speed_boost = min(
        drift_speed_boost + drift_speed_boost_rate * dt,
        drift_speed_boost_max)
```

When `is_drifting` becomes **false** (exit edge this tick):

```
drift_active = false
if drift_charge > mt_blue_threshold:
    # bank a STORED boost by tier (do NOT auto-fire)
    if   drift_charge >= mt_purple_threshold: power=320, dur=1.2, tier=purple
    elif drift_charge >= mt_orange_threshold: power=200, dur=0.8, tier=orange
    else:                                     power=120, dur=0.5, tier=blue
    boost_stored = true
    boost_stored_power / _duration / _color = ...
drift_charge = 0
drift_combo  = 0        # combo display resets; score still pending grace bank

if drift_speed_boost_enabled and drift_speed_boost > 0:
    drift_speed_boost = max(0, drift_speed_boost - drift_speed_boost_decay * dt)
```

### 15. Fire stored mini-turbo

```
if boost_pressed AND boost_stored AND NOT boost_active:
    boost_active     = true
    boost_time       = boost_stored_duration
    boost_max_time   = boost_stored_duration
    boost_power      = boost_stored_power
    boost_color      = boost_stored_color
    boost_stored     = false
    # emit boost_fired event (camera kick / SFX / flame)
```

### 16. Combo bank (grace window)

```
if NOT is_drifting and drift_combo_timer > 0:
    drift_combo_timer -= dt
    if drift_combo_timer <= 0:
        drift_total += drift_score
        drift_score  = 0
        drift_combo  = 0
```

Visible score during a run = `drift_total + drift_score`.

## D. Why this feels good (do not "improve" these)

1. **Partial lateral bleed** keeps residual slide instead of snapping onto the
   geometric heading. Hard clamps kill the hang.
2. **Asymmetric grip LERP** (fast in, slow out) makes drift release feel like
   tires clawing for grip.
3. **Yaw from slip** rotates the nose into the slide so freestyle angles stay
   recoverable with countersteer.
4. **Slew rack + self-center** kills twitchy keyboard steer.
5. **Speed grip loss** makes early apex plant and late-exit wild.
6. **Charge-on-hold / fire-on-Space** separates style from boost timing.
7. **Angle zone multipliers** reward the 23–46° sweet spot, punish >57°.

## E. Acceptance tests (required)

Implement these as unit checks against your `step()`:

1. **Idle decay** — zero input, non-zero vel → speed falls via drag/rolling;
   wheel self-centers to 0 within ~0.4 s.
2. **Straight line** — throttle=1, steer=0, no drift → approaches car.max_speed
   asymptotically, never overshoots by more than ~1% without boost.
3. **Slide on drift** — at speed ≥ 200 with drift held and steer ≠ 0,
   `|lateral_vel|` stays non-zero for many ticks (not snuffed in 1–2 frames).
4. **Grip recovery** — release drift while sliding → `current_lat_fric` returns
   to normal over ~0.28 s, not instantly.
5. **Mini-turbo tiers** — hold a scoring drift for 0.5 / 1.2 / 2.2 s then
   release → stored power is 120 / 200 / 320 respectively. Press boost once →
   `boost_active` true for the tier duration; second press does nothing until
   a new charge is banked.
6. **Scoring sign** — longer time in the 0.4–0.8 rad band should produce
   more score than shallow or over-rotated slides at the same speed.
7. **Grass** — `surface_mult = 0.45` locks top speed and grip down hard.
8. **Three cars differ** — same open-loop input sequence on muscle vs super
   yields different final headings and speeds (muscle more yaw, super more V).

## F. Integration sketch (any engine)

```
fixed_dt = 1/60
accum += frame_dt
while accum >= fixed_dt:
    input = read_input()           # or poll held actions
    car   = step(car, input, track, fixed_dt)
    accum -= fixed_dt
sprite.position = car.pos
sprite.rotation = car.heading
# VFX: tire smoke while drift_active; flame while boost_active;
# glow tier color from drift_combo thresholds (1.0 orange, 2.0 purple)
```

Track itself is just a closed polyline of control points + a width; "on track"
= distance to nearest segment ≤ width/2. Walls use the soft-push formula above.

## G. What NOT to do

- Do not replace lateral bleed with `lateral = clamp(lateral, -cap, cap)`.
- Do not use a physics engine rigid body with tire friction cones as a substitute.
- Do not auto-fire mini-turbo on drift release — it must bank, then fire on boost.
- Do not skip the gradual friction LERP.
- Do not scale yaw only from wheel angle (slip feedback is mandatory).
- Do not change the constant table "for balance" until the port matches tests.

## C. One physics tick — ORDERED ALGORITHM

Run exactly in this order every fixed `dt`.

### 0. Surface

```
on_track = surface_query(pos)   # true if on asphalt ribbon
surface_mult = 1.0 if on_track else grass_speed_mult
spd = |vel|
```

### 1. Steering rack (slew-limited + self-center)

```
target_wheel = steer * max_wheel_angle

if |steer| < 0.05:
    center = steering_center_spring * dt
    if |wheel_angle| < center: wheel_angle = 0
    else: wheel_angle -= sign(wheel_angle) * center
else:
    diff = target_wheel - wheel_angle
    max_move = steering_rack_rate * dt
    wheel_angle += sign(diff) * min(|diff|, max_move)
```

Weighty steering — never snap the wheel instantly to input.

### 2. Weight transfer (smoothed)

```
accel_factor = throttle * 0.7 - (0.6 if brake else 0.0)
target_wt    = accel_factor * weight_transfer_factor
weight_transfer_s += (target_wt - weight_transfer_s)
                    * min(1.0, weight_shift_smoothing * dt)
```

(State is kept for parity / future load-sensitive grip. The shipping step does
not multiply friction by `_wt` yet — keep the update so numbers stay ready.)

### 3. Drag

```
air_drag   = air_drag_coeff * spd * spd
rolling    = rolling_resistance * max(0, spd)
total_drag = min(spd, (air_drag + rolling) * dt)
drag_mult  = (spd - total_drag) / spd   if spd > 0.1 else 1.0
```

### 4. Speed-dependent grip loss

```
grip_t = clamp( (spd - grip_loss_start_speed)
              / (grip_loss_full_speed - grip_loss_start_speed), 0, 1 )
speed_grip = 1.0 - grip_t * grip_loss_amount
```

High speed feels looser. Low speed is planted.

### 5. World vel → car-local

```
cos_h = cos(heading); sin_h = sin(heading)
forward_vel =  vel.x * cos_h + vel.y * sin_h
lateral_vel = -vel.x * sin_h + vel.y * cos_h
```

### 6. Effective lateral friction (gradual LERP on drift press/release)

```
normal_fric = car.lat_friction_normal * speed_grip * surface_mult
drift_fric  = car.lat_friction_drift  * speed_grip * surface_mult
target_fric = drift_fric if drift else normal_fric
lerp_rate   = (1 / drift_gradual_entry_time) if drift
              else (1 / drift_gradual_exit_time)
current_lat_fric += (target_fric - current_lat_fric) * min(1, lerp_rate * dt)
lat_fric = current_lat_fric
```

Exit is slower than entry → slide-out after you release the drift button.

### 7. Lateral grip — PARTIAL BLEED (the soul of the feel)

**Do not hard-clamp lateral velocity to a ramp.** Bleed only a fraction of the
excess each tick so the car can hang off-heading.

```
lat_cap = |forward_vel| * lat_fric * (1.05 if drift else 0.95)
bleed   = lat_bleed_drift if drift else lat_bleed_normal

if |lateral_vel| > lat_cap:
    excess      = |lateral_vel| - lat_cap
    new_lateral = sign(lateral_vel) * (lat_cap + excess * (1.0 - bleed))
else:
    # gently kill residual lateral under the cap
    new_lateral = lateral_vel * (1.0 - min(1.0, lat_fric * 2.2 * dt))
```

Interpretation of `bleed`:
- `0.72` normal → keep 28% of excess slide
- `0.92` drift  → keep only 8% of excess (more control while still sliding)

### 8. Forward force / top speed / brake / active boost

```
steer_scrub = |wheel_angle| * 0.3 * (spd / 200.0)
new_forward = forward_vel * drag_mult
new_forward += throttle * car.engine_power * dt
new_forward -= steer_scrub * spd * dt

max_spd = car.max_speed * surface_mult * (1.0 + drift_speed_boost)
new_forward = clamp(new_forward, -max_spd * 0.4, max_spd)

if brake and forward_vel > 0:
    brake_force = car.engine_power * 2.0
    new_forward = max(0, new_forward - brake_force * dt)

if boost_active:
    new_forward += boost_power * dt
    boost_time  -= dt
    if boost_time <= 0: boost_active = false
```

### 9. Write local → world, rotate, integrate position

```
vel.x = new_forward * cos_h - new_lateral * sin_h
vel.y = new_forward * sin_h + new_lateral * cos_h

# Yaw = geometric rack contribution + slip-angle feedback
# so the car rotates INTO the slide (not just around the wheel)
rotate_vel = wheel_angle * (spd / 120.0) * yaw_wheel_scale
           + new_lateral * yaw_from_slip * 0.012
heading   += rotate_vel * dt

pos += vel * dt
```

### 10. Soft wall (optional coupler)

If you have a track ribbon of half-width `hw`:

```
Find closest point on centerline polyline to pos.
If distance > hw:
    normal      = (pos - closest).normalized()   # outward
    penetration = distance - hw
    pos        += normal * penetration * wall_push
    if vel · normal > 0:
        vel -= normal * (vel · normal) * wall_damp
    # emit wall_hit if cooldown allows; if mid-scoring-drift, subtract
    # min(drift_score, 100) from the open drift_score
```

Walls are a **soft push**, not a magnet and not a hard bounce.

### 11. Drift detection

```
new_speed   = |vel|
vel_dir     = angle(vel) if new_speed > 1 else heading
raw_slip    = wrap_to_pi(heading - vel_dir)     # signed, [-π, π]
drift_angle = |raw_slip|

is_drifting = drift
              AND new_speed > 60
              AND drift_angle > car.drift_threshold
```

### 12. Feint (Scandinavian flick)

Keep a ring buffer of `(time, wheel_angle)` for the last **0.35 s**.

On the frame a scoring drift first becomes true, if the recent wheel samples
contain a **sign flip** with `|wheel| > 0.15`, set once:

```
feint_bonus = feint_angle_bonus   # 0.08 rad — may be added to perceived angle
feint_applied = true
```

Clear `feint_applied` when `is_drifting` becomes false. Do not retrigger mid-slide.

### 13. Countersteer

```
is_countersteering =
    is_drifting
    AND sign(raw_slip) != 0
    AND sign(wheel_angle) != 0
    AND sign(raw_slip) != sign(wheel_angle)   # steering opposite the slide
    AND |wheel_angle| > 0.15
```

### 14. Drift scoring + mini-turbo charge + drift-speed boost

While `is_drifting`:

```
drift_combo      += dt
drift_combo_timer = combo_grace_time
drift_active      = true
drift_charge      = min(drift_charge + dt * charge_rate, charge_max)

# Angle zones
if drift_angle in [optimal_low, optimal_high]:   angle_mult = 1.3
elif drift_angle > over_rotate_threshold:          angle_mult = 0.5
else:                                              angle_mult = 1.0
if is_countersteering: angle_mult *= 1.15

combo_mult  = 1.0 + drift_combo * combo_growth_rate
score_added = drift_angle * new_speed * dt * combo_mult
              * car.drift_bonus * angle_mult
drift_score += score_added

# Sustained-drift top-speed mult
if drift_speed_boost_enabled:
    drift_speed_boost = min(
        drift_speed_boost + drift_speed_boost_rate * dt,
        drift_speed_boost_max)
```

When `is_drifting` becomes **false** (exit edge this tick):

```
drift_active = false
if drift_charge > mt_blue_threshold:
    # bank a STORED boost by tier (do NOT auto-fire)
    if   drift_charge >= mt_purple_threshold: power=320, dur=1.2, tier=purple
    elif drift_charge >= mt_orange_threshold: power=200, dur=0.8, tier=orange
    else:                                     power=120, dur=0.5, tier=blue
    boost_stored = true
    boost_stored_power / _duration / _color = ...
drift_charge = 0
drift_combo  = 0        # combo display resets; score still pending grace bank

if drift_speed_boost_enabled and drift_speed_boost > 0:
    drift_speed_boost = max(0, drift_speed_boost - drift_speed_boost_decay * dt)
```

### 15. Fire stored mini-turbo

```
if boost_pressed AND boost_stored AND NOT boost_active:
    boost_active     = true
    boost_time       = boost_stored_duration
    boost_max_time   = boost_stored_duration
    boost_power      = boost_stored_power
    boost_color      = boost_stored_color
    boost_stored     = false
    # emit boost_fired event (camera kick / SFX / flame)
```

### 16. Combo bank (grace window)

```
if NOT is_drifting and drift_combo_timer > 0:
    drift_combo_timer -= dt
    if drift_combo_timer <= 0:
        drift_total += drift_score
        drift_score  = 0
        drift_combo  = 0
```

Visible score during a run = `drift_total + drift_score`.

## D. Why this feels good (do not "improve" these)

1. **Partial lateral bleed** keeps residual slide instead of snapping onto the
   geometric heading. Hard clamps kill the hang.
2. **Asymmetric grip LERP** (fast in, slow out) makes drift release feel like
   tires clawing for grip.
3. **Yaw from slip** rotates the nose into the slide so freestyle angles stay
   recoverable with countersteer.
4. **Slew rack + self-center** kills twitchy keyboard steer.
5. **Speed grip loss** makes early apex plant and late-exit wild.
6. **Charge-on-hold / fire-on-Space** separates style from boost timing.
7. **Angle zone multipliers** reward the 23–46° sweet spot, punish >57°.

## E. Acceptance tests (required)

Implement these as unit checks against your `step()`:

1. **Idle decay** — zero input, non-zero vel → speed falls via drag/rolling;
   wheel self-centers to 0 within ~0.4 s.
2. **Straight line** — throttle=1, steer=0, no drift → approaches car.max_speed
   asymptotically, never overshoots by more than ~1% without boost.
3. **Slide on drift** — at speed ≥ 200 with drift held and steer ≠ 0,
   `|lateral_vel|` stays non-zero for many ticks (not snuffed in 1–2 frames).
4. **Grip recovery** — release drift while sliding → `current_lat_fric` returns
   to normal over ~0.28 s, not instantly.
5. **Mini-turbo tiers** — hold a scoring drift for 0.5 / 1.2 / 2.2 s then
   release → stored power is 120 / 200 / 320 respectively. Press boost once →
   `boost_active` true for the tier duration; second press does nothing until
   a new charge is banked.
6. **Scoring sign** — longer time in the 0.4–0.8 rad band should produce
   more score than shallow or over-rotated slides at the same speed.
7. **Grass** — `surface_mult = 0.45` locks top speed and grip down hard.
8. **Three cars differ** — same open-loop input sequence on muscle vs super
   yields different final headings and speeds (muscle more yaw, super more V).

## F. Integration sketch (any engine)

```
fixed_dt = 1/60
accum += frame_dt
while accum >= fixed_dt:
    input = read_input()           # or poll held actions
    car   = step(car, input, track, fixed_dt)
    accum -= fixed_dt
sprite.position = car.pos
sprite.rotation = car.heading
# VFX: tire smoke while drift_active; flame while boost_active;
# glow tier color from drift_combo thresholds (1.0 orange, 2.0 purple)
```

Track itself is just a closed polyline of control points + a width; "on track"
= distance to nearest segment ≤ width/2. Walls use the soft-push formula above.

## G. What NOT to do

- Do not replace lateral bleed with `lateral = clamp(lateral, -cap, cap)`.
- Do not use a physics engine rigid body with tire friction cones as a substitute.
- Do not auto-fire mini-turbo on drift release — it must bank, then fire on boost.
- Do not skip the gradual friction LERP.
- Do not scale yaw only from wheel angle (slip feedback is mandatory).
- Do not change the constant table "for balance" until the port matches tests.
